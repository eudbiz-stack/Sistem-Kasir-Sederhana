**Sistem Kasir Sederhana – Pondok Mengkudu**

Aplikasi kasir berbasis web yang dibangun menggunakan **PHP dan MySQL** untuk memudahkan pengelolaan transaksi penjualan. Dilengkapi dengan fitur dashboard, transaksi kasir, pengelolaan menu, laporan penjualan, manajemen pengguna, serta autentikasi login dan logout.

**Fitur Utama:**
- Dashboard
- Transaksi Kasir
- Kelola Menu
- Laporan Penjualan
- Manajemen Pengguna
- Login dan Logout

**Teknologi:** PHP, MySQL, HTML, CSS, dan JavaScript.
